# Conductor desktop experience audit — 2026-10-13

This audit compares the Mac's running Conductor with `origin/main` at `1ecd374`.
The running CLI/daemon report the older source revision `c400dd0`. The source review
therefore does not prove that a feature is installed on this Mac. No database, launch
agent, VPN, DNS setting, or S3 object was changed during the audit.

## What was verified

| Area | Observation | Status |
| --- | --- | --- |
| Local dashboard | `https://127.0.0.1:8443/` returned HTTP 200 with system TLS trust. `conductord` listens on loopback only. | Working locally on the older deployed build. |
| macOS app | Current main contains a SwiftUI `Conductor.app`, a WebKit dashboard, a menu bar item, onboarding, and storage settings. There is no `Conductor.app` in `/Applications` or `~/Applications` on this Mac. | Implemented in source; installation and interactive use unverified. |
| Updates | Sparkle 2.10.0 is pinned. The app has a manual check and automatic-check setting, and refuses updates without an embedded public key. The configured `macos-appcast` GitHub release does not exist (HTTP 404), and the repo has no appcast publishing workflow. | Update installation unavailable today. |
| Tailnet | No Tailscale app, command, process, network extension, or `ts.net` resolver was found. | Tailscale and MagicDNS unavailable on this Mac. |
| Local mesh DNS | `/etc/resolver/mesh.internal` points at Conductor's local DNS service on `127.0.0.1:15353`. It advertises ports 8443 and 8444; 8444 refused a connection. | Separate from MagicDNS; stale 8444 advertisement. |
| Data durability | The current app has S3 archive, backup, and restore controls, but `conductor storage show --json` reported `configured: false` on this Mac. `/Volumes/UgreenNAS` is mounted as an NFS share with about 7.1 TiB available. This audit did not execute a backup, restore, or S3 upload. | S3 saving is not configured here; end-to-end recovery remains unverified. |
| Responsiveness | The local dashboard HTML returned in about 0.19 seconds in one probe. `conductor doctor --json` produced no result for over 35 seconds and was interrupted; its delay was not traced to a specific check. | Browser shell reachable; CLI diagnosis latency unresolved. |
| Disk headroom | The macOS system data volume reported under 1.5 GiB available and 100% capacity during validation. A Go race build on that volume failed with `no space left on device`. | Proven build failure; effect on the live daemon or database has not been measured. |

## Priority issues and disposition

| Priority | User effect and evidence | Disposition |
| --- | --- | --- |
| P0 | The native app defaults to its own port 8080 (`macos/Sources/ConductorKit/AppSettings.swift`), while this Mac's existing server is on 8443. Its former first launch could initialize a second, empty control plane and make work appear lost. | Fixed in this change: a fresh app with no owned daemon or database waits for a choice between an existing endpoint and a new local control plane. Do not install against this live host until the native flow is built and exercised. |
| P0 | The Sparkle feed in `macos/Info.plist` is 404. `macos/README.md` documents manual signing/publication, but the release workflow ships Go archives only. | Add a signed, notarized app release and a fixed appcast publisher, then exercise an older-to-newer update on a clean Mac. Keep the updater disabled in unsigned builds. |
| P1 | The native project picker changes the dashboard URL fragment, but `Browser.show` compared only host and port (`macos/Sources/Conductor/WebView.swift`). The menu bar could follow one project while the page showed another. | Fixed in this change: navigate when the intended URL changes and apply a `#project` navigation in the SPA. Validate interactively once the app is safely attached. |
| P1 | Each SPA sign-in added two polling intervals, a visibility listener, keyboard listener, and router listeners; sign-out only stopped SSE (`internal/web/static/app.js`, `lib/router.js`). Repeated sign-ins caused extra refresh work. | Fixed in this change: tear down view, drawer, stream, listeners, and timers before sign-out or re-entry; ignore a stale organization load. |
| P1 | No Tailscale installation or MagicDNS resolver exists. `mesh.internal` is local Conductor DNS, not a tailnet name. | Install and authenticate Tailscale, enable MagicDNS in the tailnet, then expose the loopback service through Tailscale Serve and test from another device. Tailnet identity and a second device are required to verify this. |
| P1 | `conductor doctor --json` did not finish within 35 seconds in this audit, although the dashboard HTML loaded in under a second. The slow step was not identified. | Profile doctor checks separately with bounded timeouts; measure task, session, and claim UI paths before attributing overall slowness to the database. |
| P1 | The system data volume had less than 1.5 GiB free, and validation hit ENOSPC. The workspace volume had about 26 GiB free. | Reclaim or relocate verified disposable files and keep database, backup, and build headroom visible in Doctor/Settings. Do not infer a database fault from disk usage alone. |
| P1 | The package links CLI tools under `/usr/local/bin`, while this Mac resolves `conductor` from `~/.local/bin`. An app install would leave the older CLI/MCP binary first on PATH. | Add a setup check showing app, daemon, CLI, and MCP executable versions/paths, with a reviewed migration action. |
| P1 | The owner has asked for S3-backed durability, but the local storage configuration reports `configured: false`. The NAS mount is available but is a separate destination. | Choose a bucket and credential method, save the configuration, make a new non-overwriting checkpoint and base backup, and independently list and restore a test copy before relying on it. |
| P1 | Onboarding formerly offered **Skip setup** while services or sign-in could remain unresolved. `restartServices()` could switch to an attached endpoint without stopping app-owned launch agents. | Fixed in this change for the active app session: only optional steps can be skipped, completion requires a reachable signed-in project, and switching to an attached endpoint uninstalls the app-owned agents while retaining their database. An agent left by an older app session still needs a startup reconciliation check. |
| P2 | Native sign-in ignores Keychain write failure and CLI login failure (`AppModel.swift`). A successful app login can mask broken terminal/MCP access. | Surface both as explicit setup failures with retry actions. |
| P2 | The browser SSE URL contains a token query parameter. Conductor's own request logger records the path, but a reverse proxy may log the full request line. | Use a short-lived stream credential or a same-origin cookie before exposing the dashboard through another proxy. |

The current main already recreates the SPA view when its own project selector changes;
that specific browser path was not a defect. The native toolbar path above was.

## Acceptance checks for the remaining work

1. On this Mac, build and launch the app, select the existing 8443 service, and confirm
   it shows the same projects and tasks as the CLI without creating a second database.
2. A second tailnet device must resolve the Mac's MagicDNS name, open Conductor over
   HTTPS, receive live events, and use an invite. The Mac must show the Serve target and
   a working route; port 8444 must no longer be advertised unless its daemon exists.
3. A signed and notarized older app must receive, verify, and install a newer app from
   the published feed; the bundled CLI/MCP executables must update with it.
4. App, daemon, CLI, browser dashboard, storage archive, and restore must each report
   their own status. A passing UI smoke test alone does not establish data durability.
